# Rodada de Modernização - 2026-09-02

Autor: Glauco Maximo <glaucomaximo@gmail.com>

## Resumo Executivo

O projeto foi inspecionado, documentado e modernizado de forma incremental. O CRUD de tarefas foi preservado, a API ganhou rota versionada sem remover o alias legado, dependências de produção foram atualizadas e os controles locais de qualidade passaram. Naquele momento, a validação local de Docker ficou bloqueada porque o Docker CLI não estava no PATH do host; esse ponto foi resolvido na rodada de 2026-09-03.

## Alterações Implementadas

- Upgrade para Node.js 24.15.0, TypeScript 6, Angular 22 e Express 5.
- Rotas canônicas `/api/v1/tasks` com `/api/tasks` preservado.
- Fábrica testável da aplicação com injeção de repositório e verificação de prontidão.
- Prettier, ESLint, scripts de SBOM e controles de qualidade.
- README, OpenAPI, ADRs, auditoria, plano, histórico de alterações, guia de contribuição, política de segurança e runbook.

## Melhorias de Segurança

- `npm audit --omit=dev` reduziu dependências de produção para 0 vulnerabilidades conhecidas.
- Limite de requisições configurável nas rotas `/api`.
- `JSON_BODY_LIMIT` configurável.
- Erros de JSON inválido retornam 400.
- Logs estruturados com redação de chaves sensíveis.
- Varredura de padrões de segredo no CI.
- Containers sem root e sem segredos embutidos.

## Melhorias Arquiteturais

- Monólito modular preservado por ser suficiente ao escopo.
- Limite HTTP/repositório ficou testável por injeção de dependência.
- Saúde separada em vivacidade/prontidão.
- Decisões registradas em ADR.

## Alterações de Dependências

- Angular 18 -> Angular 22.
- Express 4 -> Express 5.
- TypeScript 5.5 -> TypeScript 6.0.
- Zone.js 0.14 -> 0.16.
- Removido `@angular/animations` não utilizado.
- Adicionado `@cyclonedx/cyclonedx-npm` para SBOM.
- Adicionado override de `qs` em versão corrigida para produção.

## Melhorias de Testes

- Testes HTTP com `supertest`.
- Cobertura de vivacidade, prontidão, listagem, criação, alias legado, id inválido, JSON inválido e limite de requisições.
- Suíte atual: 11 testes passando.

## Melhorias de Container e DevOps

- Dockerfiles atualizados para Node 24.15.0.
- Verificação de saúde do backend aponta para `/readiness`.
- Compose recebeu variáveis de serviço, log e limite de requisições.
- GitHub Actions cobre formatação, lint, typecheck, testes, auditoria, varredura de segredo, SBOM, CodeQL, revisão de dependências, compilação OCI e varredura Trivy.
- Dependabot configurado.

## Dívida Técnica Remanescente

- Migrações ainda não possuem histórico versionado.
- Sem teste de integração automatizado com MySQL em CI.
- Vulnerabilidades moderadas restritas ao desenvolvimento permanecem no ferramental Angular atual.
- Sem autenticação/autorização por ausência de requisito multiusuário.

## Riscos

- Docker local validado na rodada de 2026-09-03; falta automatizar esse teste em CI.
- Trivy/CodeQL rodam apenas no GitHub Actions, não localmente.
- Limite de requisições em memória não é adequado para múltiplas réplicas.

## Mudanças Incompatíveis

Nenhuma breaking change intencional. `/api/tasks` foi mantido e `/api/v1/tasks` foi adicionado.

## Instruções de Migração

Para consumidores novos, usar `/api/v1/tasks`. Consumidores existentes em `/api/tasks` continuam funcionando.

Para desenvolvimento local:

```bash
npm ci
npm run format:check
npm run lint
npm run typecheck
npm test
npm run build
```

Para Docker:

```bash
cp .env.example .env
npm run docker:up
```
