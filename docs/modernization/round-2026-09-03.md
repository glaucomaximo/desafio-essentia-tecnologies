# Rodada de Modernização - 2026-09-03

Autor: Glauco Maximo <glaucomaximo@gmail.com>

## Resumo Executivo

Esta rodada corrigiu a execução Docker local no Windows, validou o app em ambiente containerizado e aplicou sanitização adicional nos arquivos de compilação. O Docker Desktop estava instalado, mas o executável `docker.exe` não estava no PATH; ao chamar o binário diretamente, o Compose falhava porque não encontrava o auxiliar `docker-credential-desktop`.

## Alterações Implementadas

- Adicionado `scripts/docker-cli.mjs` para localizar o Docker CLI no PATH, em `DOCKER_CLI` ou no caminho padrão do Docker Desktop no perfil do usuário.
- Atualizados scripts `docker:*` do `package.json` para usar o wrapper local.
- Atualizados README e runbook de operação local com comandos reprodutíveis.
- Sanitizado `.dockerignore` para bloquear arquivos `.env.*`, caches, cobertura, chaves e certificados.
- Atualizada versão SemVer para `1.1.0`.
- Propagado `APP_VERSION` no Docker Compose para verificações de saúde coerentes.

## Melhorias de Segurança

- Reduzido o risco de envio acidental de arquivos de ambiente, chaves privadas e certificados para o contexto de compilação Docker.
- Mantida configuração externa por variáveis de ambiente.
- Mantida execução sem root nas imagens.

## Melhorias de Container e DevOps

- `npm run docker -- --version` validado com Docker 29.7.2.
- `npm run docker -- compose version` validado com Docker Compose v5.4.0.
- `npm run docker:config` validado com sucesso.
- `npm run docker -- compose up --build -d` executado com compilação real das imagens.

- Interface validada no navegador em modo Docker e modo desenvolvimento local, sem erros de console.

## Atualização 2.0.0 - Desafio Extra

### Resumo Executivo

Esta atualização implementa o desafio extra opcional: autenticação de usuários com JWT e integração com MongoDB para armazenar informações adicionais das tarefas.

### Alterações Implementadas

- Adicionadas rotas `/api/v1/auth/register`, `/api/v1/auth/login` e `/api/v1/auth/me`.
- Protegidas as rotas de tarefas com `Authorization: Bearer <token>`.
- Adicionado vínculo `owner_user_id` em tarefas para isolamento server-side por usuário.
- Adicionados metadados de tarefa em MongoDB: prioridade, prazo, etiquetas e observações.
- Atualizado frontend Angular com cadastro, login, logout e edição dos metadados.
- Atualizado Docker Compose com serviço MongoDB, healthcheck e volume persistente.
- Atualizada documentação de arquitetura, API, operação, segurança e OpenAPI.

### Melhorias de Segurança

- Senhas armazenadas com `scrypt`, sal aleatório e comparação em tempo constante.
- JWT com segredo externo, emissor, audiência e expiração configuráveis.
- `JWT_SECRET` obrigatório em produção.
- Autorização aplicada no servidor para reduzir risco de IDOR/BOLA.

### Validação

- Testes unitários e HTTP do backend ampliados para autenticação, autorização, isolamento por usuário e metadados.
- `npm run format:check`, `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`, `npm audit --omit=dev --audit-level=moderate` e `npm run sbom` executados com sucesso.
- Docker Compose validado com MySQL, MongoDB, backend e frontend saudáveis.
- Smoke test Docker e desenvolvimento local passaram com cadastro, JWT, criação de tarefa com metadados, PATCH, listagem e remoção.
- Varredura Trivy local das imagens backend/frontend retornou 0 achados HIGH/CRITICAL.

## Atualização 2.1.0 - Frontend Angular Moderno

### Resumo Executivo

Esta atualização moderniza o frontend para o paradigma atual do Angular: aplicação zoneless, Signals, componentes standalone, novo control flow e carregamento diferido. A interface foi ajustada para uma experiência SaaS operacional inspirada nos sinais de produto estudados no Easy Health: módulos integrados, segurança/LGPD, dados em nuvem e uso multi-dispositivo.

### Alterações Implementadas

- Removido `zone.js` das dependências e dos polyfills do Angular.
- Ativado `provideZonelessChangeDetection`.
- Criada fachada `TaskWorkspaceFacade` para concentrar autenticação, formulários, filtros e chamadas HTTP.
- Expostos dados HTTP de tarefas ao template por `toSignal`.
- Criados componentes standalone `AuthPanelComponent`, `TaskFormComponent` e `TaskListComponent`.
- Migrados templates para `@if`, `@for`, `@switch` e `@defer`.
- Lista de tarefas carregada como chunk lazy com `@defer (on viewport; prefetch on idle)`.
- Integrado Tailwind CSS 4.3.3 via PostCSS.
- `AuthStorage` protegido para SSR/hydration com `isPlatformBrowser`.

### Decisão Bloqueada

TypeScript 7.0.2 está disponível no npm, mas não foi instalado porque Angular 22.1.5 suporta oficialmente TypeScript `>=6.0 <6.1`. O projeto permanece em TypeScript 6.0.3 até haver compatibilidade oficial.

### Validação

- `npm --workspace frontend run typecheck` passou.
- O build de desenvolvimento gerou o chunk lazy `task-list-component`, confirmando o efeito do `@defer`.
