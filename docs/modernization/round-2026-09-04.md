# Rodada de Modernização - 2026-09-04

Autor: Glauco Maximo <glaucomaximo@gmail.com>

## Objetivo

Elevar a solução de MVP técnico robusto para uma base mais próxima de operação contínua, mantendo modernização incremental e sem reescrever o sistema.

## Alterações

- Adicionado endpoint `/metrics` em formato Prometheus.
- Registradas métricas de requisições HTTP com método, caminho normalizado, status e duração.
- Adicionado teste E2E Docker em `scripts/e2e-smoke.mjs`.
- Incluído job E2E Docker Compose no GitHub Actions.
- Fortalecidos cabeçalhos de segurança do Nginx do frontend.
- Ajustado build Angular de produção para evitar CSS crítico inline e permitir CSP mais restritiva.

## Validação Esperada

```bash
npm run format:check
npm run lint
npm run typecheck
npm test
npm run build
npm run docker:up:detached
npm run test:e2e
```

## Riscos Remanescentes

- Vulnerabilidades moderadas de desenvolvimento permanecem vinculadas ao ferramental Angular atual e devem ser reavaliadas quando houver release compatível.
- OpenTelemetry distribuído, assinatura de imagem OCI e política de deploy ainda dependem de ambiente alvo.

## Próxima Prioridade

- P1: proteção de branch exigindo checks.
- P1: estratégia de rotação/revogação de JWT para produção.
- P2: testes de frontend caso a interface cresça.
- P2: migração para TypeScript 7 quando o Angular declarar suporte oficial.
